# 文档与任务列表轮询恢复

用户现象：首次上传后 documents/tasks 状态请求连续500，刷新页面后恢复，后台文档仍在解析。

已确认前端原因：文档、任务列表每2秒轮询，Axios 每个失败请求各显示全局 toast；refreshData 本身会保留列表并重试，但重复弹窗和“请重试”提示使恢复过程不清晰。无法仅凭500截图确认本次是后端连接被拒绝、API重启还是数据库/业务异常；已请求对应Vite/NestJS日志或Response，尚待补充。

修复：仅此两个列表接口由文档管理面板统一展示失败横幅，保留401认证处理和其他操作错误；失败按2/4/8/10秒退避，成功清除横幅和失败计数；整轮请求通过allSettled收敛后再重试，继续保留已有列表，不重发上传请求。

验证：模拟两个接口连续500，再恢复200，浏览器测试确认无需刷新、无重复列表错误toast、自动恢复。vue-tsc和前端构建通过。只读审查未发现新增实质问题。后端500触发源仍未定位，不将此交互修复称为后端故障已修复。
