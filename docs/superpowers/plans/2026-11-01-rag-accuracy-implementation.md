## 工作项

- [x] 评估基线工具及60题合成标注问答集（独立人工审核尚未完成）。
- [x] API模型适配、tokenizer、父子结构、BM25倒排元数据、版本迁移。

- [x] 普通/流式会话契约、异步幂等、QA队列、摘要快照与历史。

实施按 Superpowers 子任务开发：基础层、检索引擎及前端边界并行，主线程负责会话与队列集成和审查。服务密钥缺失的真实模型评测不能标记为通过；业务数据库迁移由用户显式执行，测试仅使用隔离环境。

## 决策与证据

- 默认外部API；长文档首次提问后台生成；中文embedding升级独立1024维空间，旧384维保留。
- QA作业复用 processing_tasks，使用独立 qa 队列，快照与加密临时请求凭据仅对Worker开放。
- 暂不自动提交、推送、迁移用户数据库或调用付费模型。

## 最终验证与审查记录

- 后端55单测、13接口测试；前端23浏览器测试及2 SSE单测；前后端构建通过。
- 真实专用MySQL/Redis/Qdrant集成14项通过，包括Redis中断恢复、Worker重启、QA独立队列持久化、新旧384/1024空间隔离。Redis仅停启redis-test。
- 后续重跑曾因Docker引擎未启动而全部连接失败；启动Docker并等待专用容器健康后重跑14项成功，没有将环境失败计为通过。
- 独立审查中断于代理额度限制；已接收的两项问题由主线程补回归并修复：SSE历史诊断丢失、摘要缓存唯一键并发冲突。
- 主线程补查修复：规划API不可用时明确全文总结意图不能降为局部检索，回归RED→GREEN；无效token预算配置启动拒绝。
- 同步问答不承诺requestId幂等，批准方案要求的异步QA幂等已有持久化与真实队列验证。
- 预检确认当前缺少EMBEDDING_TOKENIZER、CHAT_TOKENIZER，Embedding独立密钥未配置；真实模型评测dry-run状态not_run，60题状态authored_requires_human_review，不宣称90%/95%目标达标。
- 原有Sass legacy API与大包体构建提示保留。运行与升级步骤见 docs/rag-quality-deployment.md。
