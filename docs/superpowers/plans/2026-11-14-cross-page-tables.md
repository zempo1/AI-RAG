# 跨页续表知识与引用修复

目标：原PDF39/40页的HL/NHL表在任一部分被检索命中时，另一部分同时提供给回答，并保存两页准确引用框；不混入第40页第9节的正文。

设计：
- 解析本地PDF矢量表格边框，给native块记录精确table范围、列/行边界与稳定groupId。相邻页尾/页首、列结构相同、无新标题插入的表格记录续接关系。流式解析只保留一页等待续页，保持文字偏移稳定。
- 切块保留table身份，禁止与同页非表格正文拼成父块。检索根据groupId双向展开；组合引用用现有sourceSegments保留各页连续原文切片，展示完整Markdown表，合并两页实际anchors。
- 旧索引原件文字和坐标齐全时，用严格的相邻页原生行/列布局识别续表作兼容；不覆盖已保存历史引用，不写真实DB，不自动重建。
- 不对任意相邻页面盲目合并，普通新表/不同列数/新标题/中间正文必须拒绝；没有可靠几何的扫描表保守保持原件区域，不捏造位置。

验证：真实原件本地39/40页定位，完整表包含B症状和病程但不含第9节；任一页检索均能返回完整来源，两页高亮与快照历史往返一致。补解析/流式offset、切块/检索/预算/不误合并回归，运行构建及完整测试。禁止外部模型验证。
