真实根因闭环：PDF.js constructPath(endPath)仅设置裁剪却记录下游文字依赖边界，旧算法将其当作图元。现在legacy/hybrid统一跳过非绘制路径，保留stroke/fill；CH3 176页兼容路径490→86个候选，受控500ms模拟视觉、并发3：91.24→22.14秒。39页零区域/零模型，74页一个完整时隙图，真实百炼1请求407token；中文扫描OCR真实识别2行，最低置信0.9577。物理层23页裁剪及高低折射率文字已核对，另两次真实百炼（1052/975token）；合计3次真实调用，未超过12次预算。

Ruling: CPU逐页版面实测139次layout+9次OCR使完整混合模式达274.04秒，因此增加默认原生图文快速分流：可靠文字层与明确真实绘图边界直接裁剪；扫描、乱码、文字不足、无框线表格疑点和边界不确定才本地模型。原生文字截图可能直接由视觉模型OCR，换取省去重复版面推理；不得以文字量单一指标跳过扫描识别。开关PDF_ANALYSIS_NATIVE_FAST_PATH=false可强制模型路径对比。
