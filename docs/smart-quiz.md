# 智能测验与面板调宽

在文档管理中对已就绪的资料点击“用于工作台”，再打开工作台“智能测验”。点击生成，可设置 1～20 题（默认10题），选择单选、多选或混合，并通过滑块调整整数题数比例。生成由后台 Worker 执行，刷新或离开不会丢失任务；失败可重试，进行中可取消。

生成后默认在右侧扩展面板练习。单选点击即判题，多选提交后判题；多选必须完整匹配正确选项，每题等权计分。答案、未提交选择、当前题号和成绩保存在服务端。历史题集可以继续、查看结果、重做或删除；重做创建独立记录，保留以前的成绩。

提交本题后可点击“解释”，系统在当前知识库聊天中发送题目和作答，要求 AI 对照原文核对参考答案。聊天输入草稿与来源选择保留；当前正在生成回答时先等待。全屏解释会回到双栏，小屏则显示聊天，并提供“返回测验”。文档更新后旧题仍可练习，但需重新生成后才能使用 AI 解释。

桌面宽度达到1200px时，侧栏与聊天之间、聊天与右侧面板之间都有分隔条。支持拖动、键盘左右键（16px，Shift为48px）、Home/End。双击恢复默认宽度。宽度按账号及面板类型保存在当前浏览器。全屏支持 Esc 退出，退出后恢复宽度与作答状态。小屏使用覆盖式面板。

## 升级与启动

此版本新增 `quizzes`、`quiz_attempts` 两张表。现有数据库在后端目录执行：

```powershell
npm run schema:upgrade
```

空数据库使用原有 `npm run migration:run` 流程。升级后重启 API 与 Worker，再启动前端；生成任务复用现有 Redis/BullMQ 配置，memory 模式也支持。应用不会自动修改数据库结构。

旧摘要接口及数据继续保留，原来的文档大纲、学习卡片和问答摘要不变。删除来源文档或知识库时，测验及练习记录随来源清理。生成过程中来源替换或任务取消后，不会发布过期结果。

## 接口

- `POST /api/quizzes/generate`：`documentId`、`singleCount`、`multipleCount`、UUID `requestId`；返回202与任务ID。
- `GET /api/quizzes/workspace?knowledgeBaseId=…`：题集历史及生成任务。
- `GET/DELETE /api/quizzes/:id`：读取或删除题集。
- `POST /api/quizzes/:id/attempts`：携带UUID `requestId`创建练习，同一请求重复发送返回相同记录。
- `GET /api/quiz-attempts/:id`：恢复练习。
- `PATCH /api/quiz-attempts/:id/progress`：保存 `currentIndex`，或 `questionId`、`selectedOptionIds`、`submit`。
- 原聊天接口可附加 `quizContext: {attemptId,questionId}`；服务端校验已提交题目、归属和来源版本后构造讲解上下文。

未提交题目不会返回正确答案与解析；判题在服务端完成，已提交答案不可改写。

出题时由服务端给连续原文片段分配来源编号，模型只选择编号，引用文本由服务端回填，避免 PDF 排版差异或模型抄写改动造成失败。若每批两题的模型输出达到长度上限，生成器自动改为每批一道继续处理；题目总数和题型配比保持不变，整套通过校验后才保存。

## 界面设计

使用 UI/UX Pro Max 的交互、可访问性及 Vue 建议，沿用项目既有深色背景与紫色强调色。整体风格检索未匹配当前产品的深色学习工作区，因此不引入检索中偏儿童教育的字体/拟物风格。选项以文字、图标和边框共同表达结果，提供可见焦点、明确保存状态、失败重试和非拖拽操作入口，并尊重减少动态效果设置。
