# 答辩演示与固定评估

创建“实验室”和“图书馆”两个私有知识库，分别上传 lab-v1.md 和 library.md；按 cases.json 记录答案、实际引用、首字响应时间和总响应时间。再用“替换”上传 lab-v2.md，等待任务完成后重复问题。

建议演示顺序：

1. 相同“开放时间”问题在两个库引用不同文件，不能跨库混答。
2. 文档任务显示解析、向量化、索引写入过程；刷新后进度仍存在。
3. 用 lab-v2.md 替换旧实验室规定，处理期间旧答案可用；完成后变为 60 天及 20:00。
4. 在答案中点击引用编号，核对文件、段落和原文；重新打开聊天仍可查看。
5. 触发全库重建，观察逐文档进度；重建期间旧索引可查询。
6. 删除来源后新提问不再引用该文件，历史消息仍显示已删除来源的快照。
7. 用另一个账号尝试访问同一知识库 ID，返回 404。

记录“答案包含预期事实”的比例、实际引用是否支持结论、错误跨库引用数、处理耗时。目标是隔离与溯源正确；不预设接入 Qdrant 会提高模型语义理解能力。不同模型或阈值的效果比较需使用同一批问题单独评估。

自动化集成测试使用固定向量与固定模型响应来隔离网络服务的不确定性；npm run test:embedding 另验证真实本地模型的 384 维输出与查询一致性。本目录用于真实模型答辩评估，不伪造评估分数。
