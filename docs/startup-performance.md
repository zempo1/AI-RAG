# 首屏加载与历史列表

`GET /api/chats` 返回当前用户的会话摘要（标题、ID、知识库、创建时间及只读状态），不包含消息、引用和任务。点击会话后调用 `GET /api/chats/:id` 读取完整历史；详情请求内按文档 ID 复用引用状态查询，缓存不跨请求，来源删除/版本过期状态仍每次重新读取。历史原文快照不改写，旧会话的默认知识库迁移仍在读取详情时处理。

工作台自己负责首次加载当前标签的数据，应用层不重复加载思维导图。文档管理只在面板打开、上传或等待工作台来源激活时读取数据；隐藏面板切换知识库只清理旧状态。打开管理面板、分页、任务轮询保留原有刷新行为。`pageSize=20` 用于管理列表，`pageSize=100` 用于问答来源选项，属于不同请求。

2026-11-15，同一本地数据只读服务层测量：

| 指标 | 修改前 | 修改后 |
| --- | ---: | ---: |
| 会话摘要 SELECT | 373 | 2 |
| 会话列表 JSON | 1,067,580 字节 | 787 字节 |
| 会话列表服务层耗时（单次样本） | 984ms | 5ms |
| 首屏初始化请求 | 11 | 7 |

耗时不含浏览器资源加载、代理和 HTTP 开销，不代表所有环境的固定延迟。请求计数通过真实组件和模拟 API 验证，数据测量未调用模型或改写数据库。无需数据迁移，部署新版前后端即可生效。

## 全项目请求审计与进一步优化

本轮在上述首轮结果基础上，将首屏请求从7条进一步减少到4条（会话摘要、知识库、当前工作台标签、问答来源选项）。跨知识库切换会话从5条减少到2条（会话详情、来源选项）；同知识库切换只读会话详情。文档管理打开后才读取文档20条分页、分类和知识库任务。

| 范围 | 发现及处理 |
| --- | --- |
| 文档管理 | 隐藏时停止无用途预读；相同筛选的在途刷新复用；分类仅在打开面板、切库或变更后读取；搜索输入250ms合并，`resume`六次请求减少到一次；分页/状态筛选立即生效。 |
| 问答来源 | 首次及切库读取可用文档；展开选择器复用相同在途请求，切库/卸载中止过期请求。不长期缓存权限或文档可用性。 |
| 会话详情 | 相同会话在途请求复用；切换会话、新建或卸载时取消旧请求，旧结果不能覆盖当前会话。后台任务完成后重新读取历史仍保留。 |
| 工作台 | 按标签加载和失效；更新来源只刷新当前标签，其余下次访问读取；同标签在途复用，失败可重试；生成、保存、删除使旧响应失效，删除项不会被旧请求恢复。 |
| 引用阅读器 | 折叠快照不请求扩展原文或备用图片；展开才读取，折叠取消；成功上下文在当前引用内复用。正常PDF预览/Range、搜索、定位仍按需进行。 |
| 导图和分析列表 | 已授权导图记录直接使用，不逐条重读；同一来源文档在单次列表请求中仅读取一次，版本状态不跨请求缓存。 |
| 知识库列表 | 已有默认库时只读一次，无需进入默认库创建事务；首次访问缺省库仍加锁复查创建。 |
| 模型设置/检索过程 | 已经是打开对话框/调试面板才读取，保留按需行为。 |
| 任务轮询/上传 | 单轮完成后再继续、有终态停止或空闲暂停；活动任务、断点上传检查与每块提交属于必要调用，保留。 |
| 权限与删除状态 | 用户存在验证、知识库/文档归属、版本和事务内重验均保留；这些校验不能作为重复调用删除。 |

仍可进一步优化的数据库开销（不属于本轮重复HTTP触发）：文档列表目前先读取完整文档行再在内存过滤分页；任务列表读取任务payload后再筛选展示条目。大数据量场景应补专用字段投影与数据库分页，不能简单缓存任务状态或去掉来源内容字段。导图/分析列表的data/content仍被编辑器与卡片使用，移除需同时改为详情按需读取。认证用户查询和模型设置还有字段投影/内部读复用空间，未取消任何校验。
